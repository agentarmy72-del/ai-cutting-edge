## Ready to try
**jundot/omlx · Try · Apache-2.0 · Maturing**

Serves local language, vision, OCR, embedding and reranking models through OpenAI-compatible APIs on Apple Silicon, for Mac users who want an offline endpoint for apps and agents. Start with the DMG and a small model on the default loopback address; macOS 15+ and adequate unified memory are mandatory, network use needs an API key, and performance claims should be reproduced on your hardware.

[Open repository ↗](https://github.com/jundot/omlx)

**immich-app/immich · Try · AGPL-3.0 code / restricted face models · Mature**

Adds local CLIP/object search and facial clustering to a mature self-hosted photo and video library, for people replacing a cloud gallery without giving up AI search. Trial it with Docker Compose and a few non-sensitive photos on a private host with at least 6GB RAM; keep separate media backups, harden port 2283 before wider access, and check InsightFace's separate restrictions before commercial use.

[Open repository ↗](https://github.com/immich-app/immich)

## Test carefully
**mattpocock/skills · Test carefully · MIT · Maturing**

A composable library of coding-agent skills for requirements, issue triage, TDD, architecture, debugging and review, aimed at engineers who want methods rather than a monolithic framework. Install only one or two editable skills with `npx skills@latest add` in a disposable branch and read the Markdown first; some skills write files, run commands or publish to trackers through your agent, so provider data rules apply and the claimed workflow gains are not independent evidence.

[Open repository ↗](https://github.com/mattpocock/skills)

**obra/superpowers · Test carefully · MIT · Maturing**

An opinionated cross-harness workflow that takes coding agents from brainstorming and design approval through worktrees, plans, subagents, TDD and review. Use the official plugin in a throwaway repository before real work: skills auto-trigger, hooks and agent commands can change Git state, the optional visual companion makes a version-only network request unless disabled, and multi-agent runs can consume substantial model budget.

[Open repository ↗](https://github.com/obra/superpowers)

**santifer/career-ops · Test carefully · MIT · Maturing**

A local-first job-search workspace that scans public ATS sources, scores roles against a CV, tailors documents and tracks applications, for jobseekers willing to supervise an AI CLI. Start with `npx @santifer/career-ops init` and synthetic profile data; expect Node plus a Chromium download, real CV/history goes to the chosen model provider, portal rules still apply, and every generated claim or autofilled form needs review—the project intentionally never submits.

[Open repository ↗](https://github.com/santifer/career-ops)
