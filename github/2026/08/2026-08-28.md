## Ready to try
**livekit/agents · Try · Apache-2.0 framework; model licence separate · Mature, active**

Builds real-time voice and video agents with pluggable speech, model and telephony components for product teams. Install the relevant `livekit-agents` extras and run one synthetic `console` session first; a real deployment needs LiveKit Cloud or a self-hosted server plus provider credentials, audio and transcripts follow those services, and LiveKit’s turn-detection models carry a framework-only licence.

[Open repository ↗](https://github.com/livekit/agents)

## Test carefully
**ChromeDevTools/chrome-devtools-mcp · Test carefully · Apache-2.0 · Maturing, active**

Exposes Chrome’s console, network, performance, PWA and heap tools to coding agents through MCP. Add `npx chrome-devtools-mcp@1.8.0` to one client and test a throwaway page with `--isolated --no-usage-statistics`; telemetry is on by default, web content can prompt-inject the agent, and attaching a real profile or opening a debug port exposes browser data and control.

[Open repository ↗](https://github.com/ChromeDevTools/chrome-devtools-mcp)

**abi/screenshot-to-code · Test carefully · MIT · Maturing, concentrated**

Turns screenshots, Figma designs and recordings into frontend code for designers and developers. Use a synthetic image in the hosted demo, or self-host with one provider key; even local use sends the image and prompt to that provider, setup spans Python, Poetry, pnpm and optional Chromium or Docker, the supplied Compose file publishes backend port 7001 on all host interfaces, and output fidelity remains project-demonstrated.

[Open repository ↗](https://github.com/abi/screenshot-to-code)

**bilawalsidhu/gods-eye-view · Test carefully · MIT code; data terms vary · Experimental, single-maintainer**

Combines public aircraft, ship, satellite, fire, weather and camera feeds on a 3D globe, with optional OpenAI voice, for OSINT learning and geospatial demos. Clone it, set a URL-restricted, quota-limited Google Maps key and keep the Vite server on localhost; Node 24 or 26 and billing are required, voice sends scene and audio context to OpenAI, some data is non-commercial or separately licensed, and the project warns that delayed or inferred data is not operational intelligence.

[Open repository ↗](https://github.com/bilawalsidhu/gods-eye-view)
