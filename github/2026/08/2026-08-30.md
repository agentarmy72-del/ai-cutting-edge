**unclecode/crawl4ai · Test carefully · Apache-2.0 text + attribution addendum · Maturing, maintained**

Turns web pages into Markdown and structured data for RAG and agents. Install `v0.9.2`, run setup and doctor, then crawl a site you control through the Python library without an LLM; requests reach target sites, optional LLM extraction sends page content to that provider, and browser profiles, cookies, hooks or the Docker API widen privilege.

[Open repository ↗](https://github.com/unclecode/crawl4ai)

**mvanhorn/last30days-skill · Test carefully · MIT · Maturing, active**

Researches public and social sources, clusters coverage and saves a cited brief for creators and analysts. Pin `v3.21.1`, run `--preflight`, then try keyless sources with `--no-browser-cookies`; queries reach selected services, optional providers receive them, and X cookie mode can read logged-in browser credentials. Coverage and synthesis quality remain project-claimed.

[Open repository ↗](https://github.com/mvanhorn/last30days-skill)

**every-app/open-seo · Test carefully · MIT · Experimental, concentrated**

Self-hosts keyword, ranking, backlink and site-audit workflows plus MCP. Run `v0.1.6` with loopback Docker, disable telemetry and use DataForSEO's trial credit; that service receives queries and later charges usage, optional OpenRouter receives AI prompts, and Google integrations retain encrypted OAuth tokens. Docker mode has no application auth, so never expose it directly.

[Open repository ↗](https://github.com/every-app/open-seo)

**corsairdev/corsair · Test carefully · Apache-2.0 · Experimental, high-churn**

Unifies app integrations for agents and backends, with tenant data, encrypted credentials and approval policies. Start with a development Hub project, SQLite and one read-only plugin in a disposable app; synced data and tokens live in your database, but Hub handles OAuth callbacks and delivery, while agent writes can touch real accounts. Protect the KEK and use cautious permissions.

[Open repository ↗](https://github.com/corsairdev/corsair)

## Watch
**pollen-robotics/microduck_rl · Watch · Apache-2.0 · Experimental, active**

Provides CUDA/MuJoCo reinforcement-learning environments and ONNX export for Pollen Robotics' small biped. Start in simulation with a trusted checkpoint; training needs Python 3.12, `uv` and CUDA, while optional Hugging Face Jobs and W&B upload source, checkpoints and metrics. With no release or security policy—and project notes documenting violent real-robot behaviour from reward errors—physical deployment needs staged expert testing.

[Open repository ↗](https://github.com/pollen-robotics/microduck_rl)
