## 🧰 Ready to Try
**jundot/omlx · Try · Apache-2.0 · Maturing**
Runs local language, vision, embedding and reranking models on Apple Silicon behind an OpenAI-compatible API. Mac users can start with the documented DMG or Homebrew route; it requires macOS 15+ and should remain locally bound unless properly secured.
[Open repository ↗](https://github.com/jundot/omlx)

## 🛡 Use Carefully
**usestrix/strix · Test carefully · Apache-2.0 · Maturing**
An AI-assisted penetration-testing system that dynamically tests applications and produces validated findings. It is directly useful to developers and security teams, but requires Docker and a model provider—and must only be run against systems you are authorised to test.
[Open repository ↗](https://github.com/usestrix/strix)

## 🔬 Frontier Watch
**cactus-compute/needle · Watch · Apache-2.0 · Experimental**
A 45M-parameter, 14MB model for tool calling and structured extraction on constrained devices, with a simple Python package and offline inference. It is promising for embedded automation, but its benchmark claims are project-authored and need independent testing.
[Open repository ↗](https://github.com/cactus-compute/needle)
