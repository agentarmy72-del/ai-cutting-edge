## Ready to try
**Comfy-Org/ComfyUI · Try · GPL-3.0 · Mature**

A mature node-graph engine for local image, video, audio and 3D generation, aimed at creators and production developers who need reusable workflows. Start with an official desktop or portable build, a small model and no custom nodes on the default loopback address; hardware and model licences vary, custom nodes are arbitrary Python, and use `--disable-api-nodes` when the core must stay offline.

[Open repository ↗](https://github.com/Comfy-Org/ComfyUI)

## Test carefully
**virgiliojr94/book-to-skill · Test carefully · MIT · Maturing**

Turns PDFs, EPUBs and document folders into indexed agent skills for developers and technical readers. First run `python3 scripts/extract.py --check` against a small openly licensed document from this canonical repository—the maintainer has warned about a malicious similarly named re-upload; extraction stays local, but cloud-agent generation may transmit text, the generated-skill scan is advisory, and redistribution can raise copyright issues.

[Open repository ↗](https://github.com/virgiliojr94/book-to-skill)

**tinyhumansai/openhuman · Test carefully · GPL-3.0 · Early beta**

Builds a local SQLite/Markdown memory and durable workflows around a desktop personal agent, with local, bring-your-own and hosted model paths. Trial a native package with synthetic data, no integrations and `local_only` inference; standard mode can broker models, search and OAuth through OpenHuman or third parties, connected services can auto-fetch, and its early-beta privacy and sandbox claims need testing.

[Open repository ↗](https://github.com/tinyhumansai/openhuman)

**NousResearch/hermes-agent · Test carefully · MIT · Maturing**

Combines cross-provider chat, terminal tools, persistent memory, scheduled jobs and messaging for users building a local or server-hosted automation layer. Use a throwaway profile, choose Blank Slate and switch terminal tools to Docker before real work; prompts and selected context reach the model provider, the local backend inherits OS-user privileges, and Docker does not contain every in-process plugin or MCP integration.

[Open repository ↗](https://github.com/NousResearch/hermes-agent)

## Watch
**block/buzz · Watch · Apache-2.0 · Experimental**

Provides a self-hostable workspace where human and agent messages, Git events and workflows share signed identities and a searchable log, for engineering teams exploring coordinated agents. Trial the desktop plus local Docker stack with throwaway keys; it is pre-1.0, needs Postgres, Redis and MinIO, public deployments need TLS, stable secrets and backups, channel membership is the sole access-control gate, and shell agents run at operator trust.

[Open repository ↗](https://github.com/block/buzz)
