## GitHub Radar
**Monday, 24 August** · Local-first workflows lead today; gateways and agent runtimes still need deliberate trust boundaries.

## Ready to try
**AgriciDaniel/claude-obsidian · Try · MIT · Maturing**

Builds a source-cited Obsidian knowledge system with plain Markdown, provenance records and recoverable, previewed writes. Initialize a separate test vault with Python 3.11; local operations and network egress are clearly separated, but data used through a hosted agent follows that provider’s boundary, filesystem permissions remain the outer security control, and maintenance is heavily lead-concentrated.

[Open repository ↗](https://github.com/AgriciDaniel/claude-obsidian)

## Test carefully
**MadsLorentzen/ai-job-search · Test carefully · MIT · Maturing**

Turns Claude Code into a supervised workflow for scoring roles, tailoring applications and checking generated PDFs for ATS readability. Trial it in a private repository with a synthetic profile and pasted posting—not a public fork; real career data reaches the model, setup needs Python, Bun and LaTeX, optional integrations widen the boundary, and prompt-injection defences are instructions rather than a sandbox.

[Open repository ↗](https://github.com/MadsLorentzen/ai-job-search)

**openclaw/openclaw · Test carefully · MIT · Maturing**

Runs a personal assistant through a local gateway, control interface, tools and messaging channels. Start with the Control UI on a disposable OS account before connecting any channel: prompts follow the chosen local or hosted model, main-session tools run on the host unless sandboxing is configured, plugins are trusted code, and one gateway is explicitly a single-operator—not multi-tenant—boundary.

[Open repository ↗](https://github.com/openclaw/openclaw)

**tashfeenahmed/freellmapi · Test carefully · MIT · Maturing**

Combines local and hosted model providers behind one OpenAI-compatible endpoint with fallback and quota tracking. Start from its Docker Compose setup on `127.0.0.1` with one low-value key and synthetic prompts; fallback can send a request to multiple providers, the environment encryption key unlocks all stored credentials, free catalogue updates may lag the paid feed, and rapid, lead-concentrated 0.x releases provide no SLA.

[Open repository ↗](https://github.com/tashfeenahmed/freellmapi)

## Watch
**apache/maka · Watch · Apache-2.0 · Incubating pre-release**

Records model messages, tool calls, permission decisions and termination events in an append-only local workspace, giving agent developers an inspectable runtime and evaluation surface. Build from source with throwaway keys on Apple Silicon: no approved Apache release exists yet, Linux and Intel Mac are unsupported, credentials are plaintext under OS-account permissions, and external models or search still receive data.

[Open repository ↗](https://github.com/apache/maka)
