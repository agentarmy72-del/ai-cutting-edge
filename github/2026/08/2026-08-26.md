## Ready to try
**tt-a1i/archify · Try · MIT · Maturing**

Turns a repository or system description into typed, self-contained architecture, workflow, sequence, data-flow and lifecycle maps for engineers reviewing systems or changes. Open a checked-in example or use its temporary `npx skills use` path on a non-sensitive repo; the renderer validates authored structure, but source context still follows your agent provider and the checks cannot prove an inferred architecture is correct.

[Open repository ↗](https://github.com/tt-a1i/archify)

**rohitg00/ai-engineering-from-scratch · Try · MIT · Maturing**

Offers 511 build-first lessons from mathematics and machine learning through LLMs, agents, infrastructure and safety, with runnable code and downloadable books. Clone it and run the dependency-free beginner preflight and vector lesson first; advanced routes add packages, GPUs or cloud services, and its exceptional breadth is maintainer-led rather than independently accredited.

[Open repository ↗](https://github.com/rohitg00/ai-engineering-from-scratch)

## Test carefully
**browser-use/browser-use · Test carefully · MIT · Maturing**

Provides a Python agent that can browse, click, type, extract data and fill forms for developers building web automation. Start with `uv add browser-use`, a harmless task and a disposable browser profile; hosted browsers are optional, but page and session data reaches the chosen model path and an agent can submit real actions, so do not begin with saved logins or irreversible workflows.

[Open repository ↗](https://github.com/browser-use/browser-use)

**pingdotgg/t3code · Test carefully · MIT · Experimental**

Unifies Codex, Claude, Cursor, Grok and OpenCode sessions behind a local web, desktop and mobile control surface. Run `npx t3@latest` on recent Node with one authenticated CLI and a throwaway repo, then change the new-thread default from Full access to Supervised; the server owns terminal, filesystem and Git execution, while remote pairing belongs on a trusted private network.

[Open repository ↗](https://github.com/pingdotgg/t3code)

**K-Dense-AI/scientific-agent-skills · Test carefully · MIT collection / per-skill terms · Maturing**

Packages 163 research skills spanning scientific libraries, databases, analysis and laboratory integrations. Researchers should install one pinned, reviewed skill and begin with public or synthetic data—not the whole collection; individual licences and external-service rules vary, skills may install code or make network calls, automated scanning is not exhaustive, and clinical material is for research support rather than patient decisions.

[Open repository ↗](https://github.com/K-Dense-AI/scientific-agent-skills)

**anthropics/claude-plugins-official · Test carefully · Apache-2.0 directory / per-plugin licences · Maturing**

Anthropic’s managed directory combines internal Claude Code plugins with external partner entries. Browse first and inspect one plugin’s manifest, licence and hooks before installation; entries can launch MCP servers, access files or connect SaaS accounts, so data and privilege boundaries vary, and Anthropic explicitly warns that inclusion does not make every dependency or future update trustworthy.

[Open repository ↗](https://github.com/anthropics/claude-plugins-official)

**DietrichGebert/ponytail · Test carefully · MIT · Experimental**

Adds a YAGNI, reuse, standard-library and native-feature discipline for teams trying to curb agent overengineering. Trial its plain `AGENTS.md` in a disposable branch before enabling Node lifecycle hooks that inject rules into sessions and subagents; the reported 54% mean code reduction and safety results are project-run on one model with four runs per task, so judge it through your own diffs and tests.

[Open repository ↗](https://github.com/DietrichGebert/ponytail)
