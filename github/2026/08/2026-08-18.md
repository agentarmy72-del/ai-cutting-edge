## GitHub Radar
**Tuesday, 18 August** · Useful agent memory and automation projects lead today, with important privacy and execution boundaries.

## Ready to try
**akitaonrails/ai-memory · Try · MIT · Maturing**

A local-first service that turns coding-agent lifecycle events into a Git-versioned Markdown wiki and cross-agent handoffs. Trial it in zero-LLM mode with loopback-only Docker; it stores prompts and tool excerpts without encryption at rest, while configured cloud models can receive sanitized project context.

[Open repository ↗](https://github.com/akitaonrails/ai-memory)

**bojieli/ai-agent-book · Try · Apache-2.0 · Maturing**

An open book with companion experiments covering context, memory, tools, evaluation, training and multi-agent systems. Start with the English PDF or online edition and an offline demo; translations may lag the Chinese source, while live experiments can need provider keys, GPUs, browsers or external services.

[Open repository ↗](https://github.com/bojieli/ai-agent-book)

## Test carefully
**harry0703/MoneyPrinterTurbo · Test carefully · MIT · Maturing**

Automates short-video scripts, stock-footage matching, speech, subtitles and rendering for creators. The quickest trial is the Windows package or a loopback Docker/uv setup with test content; unless you select local models and assets, prompts and media queries reach external providers, and publishing adds rights and platform-policy checks.

[Open repository ↗](https://github.com/harry0703/MoneyPrinterTurbo)

**chaitanyagiri/munder-difflin · Test carefully · MIT code / restricted assets · Experimental**

A desktop harness that runs coding-agent CLIs in separate terminals and coordinates them through a local Git-backed hive. Try v0.4.4 on a disposable worktree with no production secrets: auto mode can bypass command and file prompts, provider CLIs still send data under their own terms, and bundled sprites are non-commercial unless replaced or licensed.

[Open repository ↗](https://github.com/chaitanyagiri/munder-difflin)

**volcengine/OpenViking · Test carefully · AGPL-3.0 core · Maturing**

A self-hostable context database that presents agent memory, resources and skills as a browsable `viking://` filesystem. Start on loopback with pip, the setup doctor, local models and throwaway documents; hosted model services may receive content, network deployments need authentication, and benchmark gains remain project-reported amid rapid releases.

[Open repository ↗](https://github.com/volcengine/OpenViking)

**mukul975/Anthropic-Cybersecurity-Skills · Test carefully · Apache-2.0 · Experimental**

A community—not Anthropic—library of 817 agent-readable security playbooks mapped to major frameworks. Clone it and inspect one defensive skill before enabling anything: automated CI validates structure rather than every procedure, while many skills contain offensive commands requiring written authorisation, sandboxing and human review.

[Open repository ↗](https://github.com/mukul975/Anthropic-Cybersecurity-Skills)
