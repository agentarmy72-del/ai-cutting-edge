## Ready to try
**AlexsJones/llmfit · Try · MIT · Maturing**

Ranks local language models against detected RAM, CPU and GPU, helping developers choose a viable quantisation and runtime before a large download. Run `uvx llmfit fit` first; speed and quality scores are estimates or community measurements rather than guarantees, so verify with `llmfit bench`, while downloads and benchmark sharing are explicit network actions and each model carries its own licence.

[Open repository ↗](https://github.com/AlexsJones/llmfit)

**cathrynlavery/diagram-design · Try · MIT · Maturing**

Packages 39 diagram grammars, tested HTML/SVG templates and import/export workflows for coding agents, useful for technical docs and presentations. Clone it and open the local gallery before installing the plugin; static output is script-free, but brand onboarding fetches a website and fonts, PNG export adds Playwright/Chromium, and security support follows rolling `main` rather than tagged releases.

[Open repository ↗](https://github.com/cathrynlavery/diagram-design)

## Test carefully
**openai/codex · Test carefully · Apache-2.0 · Maturing**

The Apache-licensed Rust CLI gives developers a locally running coding agent with open client code, release binaries and documented sandbox and approval controls. Install the latest stable release and use a throwaway repository with default workspace-write/on-request permissions: prompts and selected code reach OpenAI or another configured model backend, sign-in or an API key is needed, and bypassing approvals or the sandbox exposes the host.

[Open repository ↗](https://github.com/openai/codex)

**affaan-m/ECC · Test carefully · MIT · Maturing**

Bundles planning, TDD, review, memory and security workflows across Claude Code, Codex and other harnesses, with a substantial open skill and hook library. Start by reviewing and copying one skill into a disposable agent profile—not the full plugin; hooks and MCP definitions are executable configuration, model data follows the host provider, optional features vary by OS, and maintenance is heavily lead-concentrated.

[Open repository ↗](https://github.com/affaan-m/ECC)

**semantica-agi/semantica · Test carefully · MIT · Maturing**

Provides local context graphs, provenance, ontology and deterministic rule engines for teams prototyping traceable agent decisions; its useful core does not require an LLM. Use v0.6.6 or later with synthetic data and run `semantica doctor`: recent project security releases fixed a critical unauthenticated Explorer access gap plus query-injection and SSRF paths, optional connectors can move data, and claims of regulated readiness are not independent certification.

[Open repository ↗](https://github.com/semantica-agi/semantica)

## Watch
**NVIDIA-NeMo/Switchyard · Watch · Apache-2.0 · Pre-alpha**

Translates OpenAI and Anthropic request formats and routes coding-agent traffic across local or hosted backends, useful for model-routing experiments. Trial v0.2.0 on `127.0.0.1` with one test backend and credentials in environment variables; every prompt reaches the chosen upstream, the documented server path does not describe client authentication, and maintainers explicitly call it pre-alpha and not for production.

[Open repository ↗](https://github.com/NVIDIA-NeMo/Switchyard)
