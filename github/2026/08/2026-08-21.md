## Test carefully
**cursor/plugins · Test carefully · MIT per plugin · Experimental**

Cursor’s official marketplace collects agent skills, hooks and Model Context Protocol integrations for coding, review and connected services. Start with the low-risk `cli-for-agent` plugin via `/add-plugin cli-for-agent`; other plugins can inspect transcripts or files, change a worktree, launch cloud agents or access SaaS accounts, so read the manifest and commands first and test with non-sensitive data.

[Open repository ↗](https://github.com/cursor/plugins)

**santifer/career-ops · Test carefully · MIT · Maturing**

Release 1.28.0 adds native Gemini batch evaluation, broader ATS discovery, a new job-board provider and an AI-screening disclosure signal. Jobseekers can trial it with `npx @santifer/career-ops init` and synthetic profile data; real CV and role history go directly to the chosen model provider, optional browser tooling adds setup, and generated claims still need review—the project does not submit applications.

[Open repository ↗](https://github.com/santifer/career-ops)

**volcengine/OpenViking · Test carefully · AGPL-3.0 core · Maturing**

Version 0.4.16 adds remote-skill discovery for VikingBot, per-user memory-extraction policies and persistent asynchronous imports, while removing the experimental Resource Relations interfaces. New users should trial pip plus a local model and throwaway documents on loopback; existing users need the migration notes, hosted models may receive content, network deployments need authentication, and benchmark gains remain project-claimed.

[Open repository ↗](https://github.com/volcengine/OpenViking)

## Watch
**makeplane/plane · Watch · AGPL-3.0 · Mature core, basic AI**

An established project-management suite whose open core includes AI-assisted Pages and basic model-backed editing endpoints. Try a synthetic cloud workspace, or the documented multi-service self-hosted deployment if data control matters; AI tasks send prompt text to the configured external model, exposed instances need normal web hardening and backups, and teams should choose it for project management rather than advanced AI capability.

[Open repository ↗](https://github.com/makeplane/plane)
