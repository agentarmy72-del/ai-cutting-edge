## Ready to try
**asciimoo/hister · Try · AGPL-3.0-or-later · Maturing**

Indexes visited pages and local files for full-text or optional semantic search through the web, CLI and MCP. Download v0.18.0, run it on loopback and choose carefully what the extension indexes; content stays on the configured server by default, but remote embeddings send document text to that endpoint.

[Open repository ↗](https://github.com/asciimoo/hister)

**microsoft/AI-For-Beginners · Try · MIT · Mature**

Provides a 12-week beginner curriculum with runnable PyTorch and TensorFlow notebooks, quizzes and labs for learners and educators. Read it directly or use Binder for a zero-install trial; the project acknowledges some material is not state of the art, advanced labs may need a GPU, and cloud notebooks move code and data into that service.

[Open repository ↗](https://github.com/microsoft/AI-For-Beginners)

## Test carefully
**cactus-compute/needle · Test carefully · Apache-2.0 · Experimental**

Packages an openly licensed 45M-parameter tool-calling model plus inference, fine-tuning and export code for small devices. Install `cactus-needle` and test `complete()` against harmless schemas; inference is local after the initial download, but benchmarks and confidence results are project-authored, and constrained JSON still needs application-level authorization before any tool executes.

[Open repository ↗](https://github.com/cactus-compute/needle)

**earendil-works/pi · Test carefully · MIT · Maturing**

Offers an extensible terminal coding-agent harness with provider adapters, persistent sessions, skills, extensions and SDK/RPC modes. Install its npm package in a disposable repository or use the documented Docker boundary; code reaches the chosen model provider, optional install telemetry is enabled unless disabled, and Pi explicitly has no built-in filesystem, process or network permission system.

[Open repository ↗](https://github.com/earendil-works/pi)

**TauricResearch/TradingAgents · Test carefully · Apache-2.0 · Maturing research**

Coordinates LLM analyst, debate, trader and risk roles over market and news data to produce simulated decisions. Try one ticker with Python, Docker and preferably local Ollama; v0.3.1 corrected look-ahead leakage and other faults, but results remain nondeterministic, hosted providers receive requests, and this is a research scaffold—not trading advice.

[Open repository ↗](https://github.com/TauricResearch/TradingAgents)

**harry0703/MoneyPrinterTurbo · Test carefully · MIT · Maturing**

Version 1.3.5 materially adds Claude, new speech and video providers, reusable presets and several file-path protections. Trial or upgrade the Docker/uv app on loopback and set `app.api_key` before network exposure; authentication remains off by default, preset exports can contain credentials, hosted services receive prompts and media, and content rights remain the operator’s responsibility.

[Open repository ↗](https://github.com/harry0703/MoneyPrinterTurbo)

## Watch
**marin-community/marin · Watch · Apache-2.0 · Maturing research**

Provides an open foundation-model R&D stack spanning data preparation, training, post-training and evaluation, with public recipes and experiment records. Its smallest sensible trial is the CPU TinyStories tutorial with Python 3.12, `uv`, local storage and `wandb offline`; meaningful runs require substantial infrastructure, optional Hugging Face/W&B services widen the data boundary, and reported model gains are project-authored.

[Open repository ↗](https://github.com/marin-community/marin)
