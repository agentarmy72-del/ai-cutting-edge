## Try
**armory3d/armorpaint · Try · Zlib; model licences separate · Maturing, single-maintainer**

Version 1.0 gives 3D artists PBR painting plus local neural nodes for text-to-image, image editing, upscaling and image-to-PBR. The quickest trial is the paid portable build on a sample asset; compiling the open source needs a platform toolchain, while neural models need 1–16GB VRAM. Processing stays local after model download, but optional Claude/Grok/Codex console prompts leave the machine and generated scripts need review before execution.

[Open repository ↗](https://github.com/armory3d/armorpaint)

## Test carefully
**JustVugg/colibri · Test carefully · Apache-2.0 code; model licences separate · Experimental, active**

Streams the active parts of giant mixture-of-experts models from SSD, letting local-inference experimenters use weights far larger than RAM; v1.10.2 fixes conversion and diagnostic defects and hardens local-image reads. Download its checksummed platform archive and run `python3 coli info` before choosing a checkpoint; the reference GLM download is 372GB and throughput figures are project-measured. Keep its API on `127.0.0.1`, or add an API key and exact host/origin allowlists.

[Open repository ↗](https://github.com/JustVugg/colibri)

**nashsu/llm_wiki · Test carefully · GPL-3.0 · Maturing, maintainer-concentrated**

Turns documents into a persistent, cited Markdown wiki with graph and hybrid search, for researchers who want knowledge to compound rather than be reconstructed on every query. Download v0.6.11, create a synthetic project and pair it with Ollama first; hosted LLM, vision and embedding services receive source content, provider keys are saved in local app state rather than an OS keychain, and its optional agent can run approved shell commands. Keep the local API token-protected.

[Open repository ↗](https://github.com/nashsu/llm_wiki)

**Tencent/teamai-cli · Test carefully · MIT · Maturing, high-churn**

Synchronises skills, rules, documentation, MCP, hooks and searchable team knowledge across mixed coding agents—useful for engineering teams governing one shared harness. On Node 20+, install pinned v0.23.1 in a throwaway project and set `sharing.hooks.autoApply: false` plus `sharing.hooks.requireTeamScripts: true` before the first pull. Session-start pulls otherwise update executable hooks automatically; shared resources live on the chosen Git host and model context follows each host agent.

[Open repository ↗](https://github.com/Tencent/teamai-cli)

**vercel-labs/skills · Test carefully · MIT · Maturing, active**

Lists, installs and updates agent skills across dozens of coding assistants, solving a real cross-tool packaging problem. With Node 22.20+, start with `DISABLE_TELEMETRY=1 npx skills add <trusted-repo> --list`, inspect one `SKILL.md`, then install project-local without `-y`. Its remote security scores are advisory and fail open; installed instructions inherit the host agent’s file, command and network powers.

[Open repository ↗](https://github.com/vercel-labs/skills)

## Watch
**THU-MAIC/OpenMAIC · Watch · MIT core; bundled LGPL-3.0-or-later component · Maturing, high-churn**

Version 1.0.1 earns a return by fixing four published vulnerabilities in persistence writes, stored slide rendering and outbound-provider handling; users on 1.0.0 should upgrade. Educators can trial it on localhost with Node 22.19+ and synthetic material, but should not expose Compose’s port or enable `ALLOW_LOCAL_NETWORKS` on a credential-bearing cloud host yet: current `main` contains further cloud-metadata SSRF hardening not included in the tag. Prompts, uploads and media follow configured providers.

[Open repository ↗](https://github.com/THU-MAIC/OpenMAIC)
