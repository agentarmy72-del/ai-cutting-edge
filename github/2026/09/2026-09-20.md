## Try
**paperless-ngx/paperless-ngx · Try · GPL-3.0 · Established, active**

Turns scans and documents into a searchable self-hosted archive for households and document teams; v3.2 improves fuzzy/CJK search, share-link control and AI-suggestion workflows. Start with Docker Compose on a local host and copied non-sensitive documents; files are unencrypted at rest, and a hosted OpenAI-compatible backend receives the document data you send it.

[Open repository ↗](https://github.com/paperless-ngx/paperless-ngx)

**max-sixty/worktrunk · Try · MIT OR Apache-2.0 · Maturing, active**

Makes Git worktrees manageable for developers running several coding agents, with status, hooks, merges and cleanup. The v0.78 ARM64 release matched its published SHA-256 and passed create/list/remove in a disposable repository here; begin with `wt list` and one throwaway branch, because merge/remove change Git state, approved project hooks execute commands, and optional LLM commits send diffs to the configured model.

[Open repository ↗](https://github.com/max-sixty/worktrunk)

**vercel-labs/json-render · Try · Apache-2.0 · Maturing, active**

Lets app teams turn model output into web, mobile, document and video interfaces constrained to a typed component-and-action catalog; v0.21 adds TanStack Start and steadier streaming. Its packages installed and validated a constrained spec here; start with a static catalog before attaching a model, and keep action authorisation explicit because the model provider you choose receives the prompts and application context you supply.

[Open repository ↗](https://github.com/vercel-labs/json-render)

## Test carefully
**stablyai/orca · Test carefully · MIT core; hosted services partly private · Maturing, high-churn**

Provides a desktop control plane for developers running multiple CLI agents across worktrees, local machines, SSH hosts or bring-your-own cloud VMs. Trial one copied repository in local mode before pairing mobile or remote clients: launched agents retain terminal, file and optional browser authority, anonymous telemetry goes to US-hosted PostHog unless disabled, pairing links act as credentials, and parts of the hosted auth/cloud stack remain private.

[Open repository ↗](https://github.com/stablyai/orca)

**Panniantong/Agent-Reach · Test carefully · MIT · Maturing, integration-heavy**

Installs and health-checks a routing layer that lets command-line agents read or search websites, videos, repositories and several social platforms through upstream tools. A pinned source install, check-only setup and `doctor` ran in an isolated home here; start there rather than with `--system`, because optional channels add system tools, hosted readers/search services and browser cookies, while scripted social access can trigger account restrictions.

[Open repository ↗](https://github.com/Panniantong/Agent-Reach)
