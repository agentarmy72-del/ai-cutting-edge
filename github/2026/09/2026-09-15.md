## Try
**danny-avila/LibreChat · Try · MIT · Established, active; RC features experimental**

Gives teams a self-hosted, multi-user front end for chat, agents, MCP and multiple model providers. Start with Docker Compose on a private machine and one local model, leaving MCP and attached code workspaces off: v0.8.8-rc3’s final release gate passed, but no stack was run here; its default Compose publishes app and admin ports, cloud providers receive prompts or files, and BYOM shell access is explicitly experimental.

## Test carefully
**MG1937/ASC · Test carefully · Apache-2.0 · Experimental, maintainer-led**

Searches Android APK manifests, classes and cross-references on demand instead of building a global index, useful to mobile-security researchers and agent workflows. Install it in a disposable Python 3.10+ environment and begin with a benign APK; pinned source installed and all 24 bundled tests passed here, but there is no tagged release or security policy, arbitrary APKs are untrusted input, and the headline speed benchmark is project-run.

[Open repository ↗](https://github.com/MG1937/ASC)

**alphaXiv/OpenResearch · Test carefully · MIT · Experimental, high-churn**

Version 0.2.2 earns a return: it adds Windows beta support, a first-class Cursor harness, persistent managed-repository storage and an explicit run state machine. Researchers can verify the release checksum, run `orx --no-telemetry projects`, then try a toy repository with a local model; the checksummed Linux binary and basic command passed here, while agents still execute commands with user privileges, Windows builds are unsigned, and remote or cloud paths widen the data boundary.

[Open repository ↗](https://github.com/alphaXiv/OpenResearch)

**melgarafael/DeskcommCRM · Test carefully · MIT · Maturing, high-churn**

Version 1.27.1 earns a return: releases since 1.18.1 add invite-only signup, block service-role edits and deletes on audit records, and alert operators when background work—or an AI customer reply—fails permanently. Sales teams should trial it on a backed-up test VPS with synthetic contacts and a test number; tagged CI, image, invariant and E2E checks passed, but setup spans Docker, Supabase, WhatsApp and an LLM provider, so customer data crosses the services selected.

[Open repository ↗](https://github.com/melgarafael/DeskcommCRM)

**earendil-works/pi · Test carefully · MIT · Maturing, active**

The 0.85 line earns a return with restorable in-memory sessions, persistent Claude thinking effort, and fixes for tools using the wrong working directory plus session-fork and import-overwrite faults. Agent and SDK developers can install 0.85.1 with Node 22.19+ and start read-only in a disposable repository; the package installed and its CLI ran under Node 22.23 here, but Pi deliberately has no sandbox—model providers receive selected context, while tools and extensions inherit the user’s filesystem, process, network and credential access.

[Open repository ↗](https://github.com/earendil-works/pi)
