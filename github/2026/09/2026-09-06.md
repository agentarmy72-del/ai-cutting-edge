## Test carefully
**aipoch/open-science · Test carefully · Apache-2.0 · Maturing, high-churn**

Combines agent chat, Python/R notebooks, literature and data connectors, immutable artifact versions, and local project storage for researchers needing one inspectable workbench. Download stable v0.25.1, verify its checksum and SLSA attestation, and use synthetic data with approval prompts left on; setup requires an agent runtime and model provider, while model, web, connector, OAuth or remote-compute calls send needed content to those services. It executes code and can read or write files; network controls cover notebook and compute runtimes rather than the whole system, and Windows hard isolation needs one-time administrator setup while its installer remains unsigned.

[Open repository ↗](https://github.com/aipoch/open-science)

**OpenWhispr/openwhispr · Test carefully · MIT · Maturing, active**

Offers system-wide dictation, meeting transcription and AI voice actions across macOS, Windows and Linux, with a useful offline core plus optional cloud and sync services. Trial v1.9.2 signed out with a local model, a disposable recording and only microphone/accessibility permissions; leave screen context, calendar, meeting capture and cloud sync off until needed. Cloud providers receive selected audio or context, native helpers monitor hotkeys and paste into apps, and Linux secrets fall back to plaintext without a keyring. Current main also contains consent-gated Insights counter sync despite the README's blanket “no telemetry” wording, while its security policy still names 1.7.x rather than current 1.9.x.

[Open repository ↗](https://github.com/OpenWhispr/openwhispr)
