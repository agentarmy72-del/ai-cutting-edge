## Try
**microsoft/markitdown · Try · MIT · Maturing, active**

Turns PDFs, Office files, email, images and audio into structure-preserving Markdown for developers building search or LLM pipelines. In a Python 3.10+ virtual environment, install only the formats needed—`pip install "markitdown[pdf,docx,pptx]"`—then convert one non-sensitive file with `markitdown file.pdf -o file.md`; local-file conversion needs no cloud service, while LLM OCR and Azure modes send content to billable services. It inherits the caller’s file and network access, so do not expose broad conversion of untrusted paths or URLs.

[Open repository ↗](https://github.com/microsoft/markitdown)

## Test carefully
**heygen-com/hyperframes · Test carefully · Apache-2.0 · Maturing, high-churn**

Turns ordinary HTML, CSS and seekable animation into frame-by-frame video through headless Chrome and FFmpeg, useful to developers and agent-assisted creative teams that want an inspectable local workflow. With Node 22+ and FFmpeg, run `npx hyperframes init my-video`, then preview and render locally without an API key; version 0.8.31 arrived today, but anonymous CLI/Studio telemetry is enabled by default, remote assets and optional Gemini/cloud paths leave the machine, and hosted render examples need authentication, input limits and cost controls.

[Open repository ↗](https://github.com/heygen-com/hyperframes)

**bytedance/deer-flow · Test carefully · MIT · Experimental, high-churn**

Orchestrates subagents, memory, skills and sandboxes for long research, coding and creation jobs, aimed at experienced agent engineers. Trial the 2.0 rewrite via `make setup` and the recommended Docker path with synthetic files—the documented minimum is 4 vCPU, 8 GB RAM and 25 GB disk plus one model credential; selected model, search and MCP providers receive task data, while local execution, file tools and Gateway administration can carry code-execution authority. Keep the Docker sandbox and 127.0.0.1 binding, and complete account setup before any exposure.

[Open repository ↗](https://github.com/bytedance/deer-flow)

## Watch
**lightpanda-io/browser · Watch · AGPL-3.0 · Experimental, active**

Offers a from-scratch Zig headless browser with CDP and WebDriver interfaces for automation teams trying to reduce Chrome overhead. Install release 0.4.0 and run `lightpanda dump https://example.com`, then test Playwright or Puppeteer on a public site with `--obey-robots` and a 127.0.0.1 bind; there is no native Windows binary, browser compatibility remains incomplete, and its speed benchmarks are project-run. Usage telemetry is on by default, and any broader CDP bind creates a powerful control surface that needs separate protection.

[Open repository ↗](https://github.com/lightpanda-io/browser)
