## Ready to try
**addyosmani/agent-skills · Try · MIT · Maturing, active**

A portable pack of specification, implementation, testing, review and release workflows for coding agents. Start project-locally with one review skill; its bundled structural and routing checks passed in this review, but that does not prove better code, some integrations add a shell hook, and build workflows can edit and commit with the agent’s privileges while cloud-backed agents receive project context.

[Open repository ↗](https://github.com/addyosmani/agent-skills)

**f/prompts.chat · Try · MIT code / CC0 prompt data · Established library, active dataset**

A searchable public prompt collection plus a self-hostable team catalogue. Browse the raw collection before deploying; community prompts are untrusted instructions, while self-hosting needs Node 24 and PostgreSQL, Docker publishes port 4444 and allows registration by default, and optional AI features send content to the configured OpenAI-compatible endpoint.

[Open repository ↗](https://github.com/f/prompts.chat)

## Test carefully
**magnitudedev/magnitude · Test carefully · Apache-2.0 · Experimental, active**

A young local-inference service that profiles hardware, recommends GGUF model configurations and connects them to existing coding agents. Run `npm i -g @magnitudedev/cli`, then `magnitude setup` with the smallest suitable model on macOS, Linux or WSL; its endpoint stays on loopback and tracing is opt-in, but setup downloads binaries and weights, installs a login service and can rewrite harness settings, model licences vary, optional cloud and web paths move data off-device, and performance rankings are project-authored.

[Open repository ↗](https://github.com/magnitudedev/magnitude)

**anthropics/skills · Test carefully · Apache-2.0 samples / proprietary document skills · Maturing, active**

Official reference skills for frontend design, MCP building, documents, web testing and Claude API work. Trial one folder with an explicit Apache-2.0 licence after reading its instructions; there is no umbrella licence, four document skills are proprietary and `doc-coauthoring` has no declared licence, while tool-enabled skills can expose files to Claude or run local scripts.

[Open repository ↗](https://github.com/anthropics/skills)

**blader/humanizer · Test carefully · MIT · Maturing, concentrated**

A portable Markdown skill that applies 35 Wikipedia-derived cleanup patterns to formulaic AI prose. Copy `SKILL.md` into a scratch agent and inspect a side-by-side diff; its package validator passed in this review, but cloud agents receive the text, file mode can overwrite prose, and fixed heuristics may flatten voice or change meaning—they cannot establish human authorship or satisfy disclosure duties.

[Open repository ↗](https://github.com/blader/humanizer)
