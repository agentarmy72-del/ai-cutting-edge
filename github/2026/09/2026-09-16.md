## Try
**roboflow/supervision · Try · MIT · Established, active**

A model-agnostic Python toolkit for detection, tracking, annotation and dataset conversion, aimed at computer-vision developers who need reliable application plumbing rather than another model. Install from PyPI on Python 3.10+; the v0.30.3 wheel imported and a local `Detections` object ran here, while models, their licences and any API-backed data transfer remain separate choices.

**cloudflare/security-audit-skill · Test carefully · MIT · Experimental, maintainer-led**

Turns a compatible coding agent into a structured security-audit workflow with reconnaissance, coverage tracking and machine-readable findings. Its pinned checkout passed all 65 bundled validator tests here, but those test output integrity—not vulnerability-detection quality; use it only on authorised code inside the prescribed no-network OS sandbox, and remember a cloud model may receive source context.

**Tencent/WeKnora · Test carefully · MIT code; third-party terms vary · Maturing, active**

A substantial self-hosted RAG, agent and auto-wiki platform for teams turning document collections into searchable knowledge. Trial the core Docker Compose stack with synthetic documents and local models on a firewalled host; no full deployment was run here, default Compose publishes web and API ports, remote providers can receive document content, and the Docker-socket sandbox should remain disabled unless deliberately isolated.

[Open repository ↗](https://github.com/Tencent/WeKnora)

**cline/cline · Test carefully · Apache-2.0 · Established, high-churn**

Offers coding agents through an SDK, CLI, desktop app and IDE extensions, with multiple model providers and local Ollama or LM Studio support. Begin in Plan mode inside a disposable repository and keep per-action approvals enabled: remote models receive selected code and prompts, optional telemetry can be disabled, while plugins, MCP servers and scheduled agents widen filesystem, terminal and network authority.

[Open repository ↗](https://github.com/cline/cline)
