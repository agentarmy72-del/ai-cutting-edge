## Try
**dream-num/univer · Try · Apache-2.0 · Maturing, active**

Gives agent and product teams embeddable spreadsheets, documents and slides without forcing a hosted office suite; the OSS SDK also supports headless Node workflows. Start with preset Sheets in a disposable Vite app—or headless Node 18.17+—and use v0.25.2, which fixes prototype pollution in drawing and formula maps; current build, typecheck and test shards pass. Core APIs can stay inside your app, but collaboration and file conversion use separate Server/Pro packages, so review both licensing and where document data flows.

[Open repository ↗](https://github.com/dream-num/univer)

## Test carefully
**flashml-org/freetoken · Test carefully · Apache-2.0 code; model licences vary · Beta, active**

Runs open-weight language and vision models behind OpenAI- and Anthropic-compatible local APIs, using CPU/RAM offload to stretch consumer NVIDIA hardware. For a sensible trial, use stable v0.1.3 on Linux x86_64 with driver 580+, CUDA 13 and a smaller supported checkpoint such as Qwen3-VL 8B, then keep the default loopback bind. The 290B performance claim is project-reported; checkpoints still need substantial RAM and disk, remote image URLs are fetched unless allowlisted, and no inference-API authentication is documented.

[Open repository ↗](https://github.com/FlashML-org/FreeToken)

**sergebulaev/linkedin-skills · Test carefully · MIT · Maturing, maintainer-led**

Bundles 12 agent skills for LinkedIn planning, drafting, comments, replies and profile work, with a manual draft mode that needs no service account. Clone it and run its offline self-test before loading one skill; 102 tests plus frontmatter, reference and tracked-secret checks passed in a fresh virtual environment here. Optional Apify, Publora and Pixfaro paths send content or account data to hosted services, feed text is untrusted prompt input, and the custom-poster option can execute a configured local command—start with synthetic drafts and no keys.

[Open repository ↗](https://github.com/sergebulaev/linkedin-skills)

## Watch
**google/ax · Watch · Apache-2.0 · Experimental v0.3**

Adds Kubernetes-shaped Task, Workspace, Gateway and Model manifests for platform teams running agents through Agent Substrate. Its current build-and-test passes, but a real trial needs Go 1.27+, `ko`, Kubernetes, a registry, Redis and a reachable Substrate control plane; use a disposable cluster, replace the example’s wildcard HTTPS egress and leave debug guest services off. Prompts and code reach the chosen Google or Anthropic model, APIs are `v1alpha1`, and maintainers expect breaking changes.

[Open repository ↗](https://github.com/google/ax)

**agent-substrate/substrate · Watch · Apache-2.0 · Early testing, high-churn**

v0.1.0 earns a return: the Kubernetes runtime for gVisor or microVM agent sandboxes now calls itself ready for early testing, and current unit, vulnerability and end-to-end checks pass. Infrastructure teams should reproduce only the counter demo on local `kind` using Go, Docker and `kubectl`, then test tenant, egress and checkpoint boundaries before real code or credentials. Maintainers still say it is not production-ready and its APIs will almost certainly break; density and resume figures are project-claimed.

[Open repository ↗](https://github.com/agent-substrate/substrate)
