## Ready to try
**vercel-labs/portless · Try · Apache-2.0 · Maturing, active**

Gives parallel web projects and coding-agent worktrees stable named `.localhost` URLs instead of shifting ports. Install it project-locally and test one disposable app; the default stays on loopback, but HTTPS trusts a local CA and may elevate for port 443, while LAN, Tailscale and Funnel modes can expose an otherwise unprotected dev server.

## Test carefully
**google-research/timesfm · Test carefully · Apache-2.0 code / non-commercial 3.0 weights · Maturing research**

TimesFM 3.0 adds multivariate forecasting and covariates for data teams testing zero-shot time-series forecasts. Install `timesfm[torch]` and start with synthetic data on a CUDA host; inference can stay local after the model download, but 3.0 weights forbid commercial and production use, and its benchmark lead is project-claimed.

[Open repository ↗](https://github.com/google-research/timesfm)

**superlinked/sie · Test carefully · Apache-2.0 framework / per-model licences · Maturing, active**

SIE 0.7.2 puts embeddings, reranking, OCR, structured output and generation behind one self-hosted OpenAI-compatible service for agent and retrieval teams. Try the CPU image bound to `127.0.0.1:8080` with a small model; first use downloads weights, anonymous hardware and version telemetry is on unless disabled, and the quickstart shows no client-auth layer, so do not publish port 8080 directly.

[Open repository ↗](https://github.com/superlinked/sie)

**pacifio/atlas · Test carefully · MIT · Alpha, active**

Atlas links commits to the prompts, tool calls and agent sessions that produced them, while sharing on-device memory across coding agents. Try alpha-0.3.0 on a disposable macOS repository with sync off and telemetry disabled; model providers still receive selected context, imported agents and packs can execute code, and Linux and Windows builds are untested.

[Open repository ↗](https://github.com/pacifio/atlas)

**NousResearch/hermes-agent · Test carefully · MIT · Maturing, high-churn**

Version 0.21.0 materially adds persistent cron continuity, live subagent steering, bot-to-bot rooms and an agent-controlled in-app browser, alongside approval and redaction hardening. Upgrade a disposable profile and test one continuity-enabled job with a Docker terminal; prompts still reach the selected model provider, while local, MCP, browser and messaging tools widen the authority boundary.

[Open repository ↗](https://github.com/NousResearch/hermes-agent)

**affaan-m/ECC · Test carefully · MIT · Maturing, concentrated**

Run `npx --yes ecc-universal@2.2.0 install --guided` against a disposable profile and choose a minimal, no-hook setup first; context still follows the host model provider, adapters differ, and the release assurances are project-reported.
