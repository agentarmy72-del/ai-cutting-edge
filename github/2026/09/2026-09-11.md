**github/spec-kit · Try · MIT · Established, active**

**alphaXiv/OpenResearch · Test carefully · MIT · Experimental, high-churn**

Coordinates coding agents in separate git worktrees so research teams can compare hypotheses, experiments and artifacts across local or remote compute. Its checksum-matched v0.1.122 CLI ran here; start with `orx telemetry off`, a local model and a synthetic repository, because agents execute commands with your account, official builds otherwise send coarse opt-out analytics, and remote mode has no application-level authentication beyond its loopback bind.
