## Try
**docling-project/docling · Try · MIT code; model licences vary · Established, active**

Turns PDFs, Office files, images and audio into structured Markdown or JSON for RAG builders and document teams, with local and air-gapped execution available. In a disposable Python 3.10+ environment, `pip install docling` and convert a copied file; the stack includes PyTorch, optional OCR/VLM extras add hardware and licence requirements, and URLs or cloud integrations change the otherwise local data boundary.

[Open repository ↗](https://github.com/docling-project/docling)

**asciimoo/hister · Try · AGPL-3.0-or-later · Maturing, active**

Version 0.19 earns a return: it adds ChatGPT and Hacker News extraction, Safari history import, URL-regex cleanup with dry-run deletion, and richer previews to private search over visited pages and local files. Download v0.19, keep it on `127.0.0.1:4433`, and index a copied folder first; there is no telemetry or cloud sync by default, but remote embeddings receive document text and MCP clients must treat indexed pages as untrusted content.

[Open repository ↗](https://github.com/asciimoo/hister)

## Test carefully
**trycua/cua · Test carefully · MIT core; optional components vary · Maturing, high-churn**

Provides cross-platform desktop control, local Apple-Silicon VMs, cloud sandboxes and benchmarks for computer-use agent builders. Start with `cua-bench`’s simulated task, which needs no VM, Docker or model key; Driver later requires screen and accessibility authority, sends content-free telemetry by default, and should use bounded mode with a disposable profile—hosted Fleets add credentials, retained capacity and cost.

[Open repository ↗](https://github.com/trycua/cua)

**cactus-compute/needle · Test carefully · Apache-2.0 code and weights · Experimental, active**

Needle 3 earns a return: the new 8–29 MB laddered model combines local tool selection, structured extraction and embeddings across phones, browsers and small devices; benchmark and confidence claims remain project-authored. `pip install cactus-needle` and begin with extraction or mocked read-only tools; weights and engines download once, anonymous usage telemetry is on by default unless disabled, and schema-constrained output still does not authorise the Python functions `run()` can execute.

[Open repository ↗](https://github.com/cactus-compute/needle)
