**Evidence:** Confirmed by Meta on 15 September; tiers start at $14.99, $49.99, $149 and $499 monthly, but features, prices and availability vary by region, app and account.  
[Direct source ↗](https://about.fb.com/news/2026/09/introducing-meta-one-subscription-service-more-features-ai/)

**Chrome · public ad-load metrics enter CrUX · Test**
Chrome now exposes real-user ad count, viewport density, CPU weight and network weight through CrUX Vis and its APIs. Benchmark ad-funded sites, then watch for regressions after placement or tag changes.

**Evidence:** Confirmed in Chrome documentation published 15 September; these are experimental 28-day p75 metrics with no “good” threshold, and public reporting requires an ads.txt authorised seller.  
[Direct source ↗](https://developer.chrome.com/docs/ads/metrics)

**Meta · Creator Marketing Hub and Instagram live partnership ads · Test**
Meta is consolidating creator discovery, permissions, messaging and partnership-ad creation, while extending live video partnership ads from Facebook to Instagram on 29 September. Pilot with permission expiry, disclosure, brand-safety and incrementality checks.

**Evidence:** Platform-claimed rollout details reported by MediaPost on 16 September; availability and performance remain unverified.  
[Direct source ↗](https://www.mediapost.com/publications/article/418022/meta-launches-creator-marketing-hub-live-video-ad.html)

## 🛠 Marketing Tool Radar

**getopenpost/openpost · Test carefully · AGPL-3.0-only · Fast-moving 4.34.0**
v4.34.0 fixes URL retention beside media on X, Threads, Mastodon and LinkedIn, and blocks repeat clicks consuming a second MCP OAuth code. Trial a pinned disposable instance with one non-critical account; verify links, auth recovery and draft-versus-publish controls.

**Evidence:** Tagged release, full tree, actual licence, setup and security docs inspected; no live publish or OAuth test was run, so behaviour remains project-claimed.  
**Boundary:** Linux/amd64 self-hosting needs persistent storage, TLS, backups and public OAuth/media URLs; it holds social tokens, content and media, optional AI uses OpenRouter, and only the latest release gets security fixes.  
[Open repository ↗](https://github.com/getopenpost/openpost/releases/tag/v4.34.0)
