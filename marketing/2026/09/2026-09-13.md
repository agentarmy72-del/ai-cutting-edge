**Open-Web-Analytics/Open-Web-Analytics · Test carefully · GPL-2.0-or-later · Mature, upgrade-sensitive 1.13.0**
Version 1.13 adds configurable reports, an organisation/property model and goal events. Trial a fresh PHP/MySQL sandbox; existing operators should back up and inventory external report links before migrating.

**getopenpost/openpost · Test carefully · AGPL-3.0-only · Maturing, fast-moving 4.30.3**
The release prevents retries from republishing completed thread segments, preserves links after partial failures and tightens media validation. Trial one synthetic workspace and non-critical account, then reconcile scheduled items with provider URLs.

**Evidence:** Tagged release, source, licence, Compose and security documentation inspected; no account was linked and no post was sent.  
**Boundary:** The maintained image is Linux/amd64; real use stores social tokens, content, media, replies and analytics, and needs public HTTPS/media endpoints plus provider approvals. Full MCP access can publish, reply and moderate; optional AI sends content to the chosen provider.  
[Open repository ↗](https://github.com/getopenpost/openpost/releases/tag/v4.30.3)

**relaticle/relaticle · Test carefully · AGPL-3.0 · Maturing, active 3.5.8**

**Evidence:** Tagged release, source, licence, Compose and security docs inspected; the 2,000+ test figure is project-claimed and no deployment was run.  
**Boundary:** Self-hosting needs the app, PostgreSQL, Redis, a worker and scheduler. API/MCP access can mutate sensitive CRM records, and external AI sends selected context to the configured model provider.  
[Open repository ↗](https://github.com/relaticle/relaticle/releases/tag/v3.5.8)
