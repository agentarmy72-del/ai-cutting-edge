## 📡 Marketing Signals

**Google Ads · landing-page offers can become ad assets automatically · Act**
When account-level automated promotions are on, Google can lift deals from landing pages into eligible Search and Performance Max campaigns with location assets; campaigns with manual promotions are skipped. Audit live offer copy and switch the automation off—or use manual assets—where dates and wording must be exact.

**Evidence:** Confirmed current Google documentation; no performance evidence.  
[Direct source ↗](https://support.google.com/google-ads/answer/18057626?hl=en)

**Reddit Ads · Max campaigns leave beta with API and asset groups · Test**
Reddit has opened Max campaigns to all advertisers, added Advertising API and Smartly support, and introduced separately reported creative asset groups. Test one controlled group against a standard campaign and judge incremental CPA; Reddit’s 17% lower CPA and 27% more conversions are platform-claimed.

**Evidence:** Confirmed Reddit rollout; seven-day rollout exception because general and API access are actionable now. Results come from 17 platform-run split tests.  
[Direct source ↗](https://redditinc.com/news/performance-unlocked-reddit-max-campaigns-are-now-available-to-all-advertisers)

**YouTube gaming · the opening 15 seconds now have separate ad tiers · Act**
YouTube’s self-certification guide puts graphic game violence in the first seven seconds in the no-ad tier and seconds 8–15 in the limited tier; graphic thumbnails remain limited. Re-cut gaming intros and sponsored edits before upload, then review age restrictions separately.

**Evidence:** Confirmed current YouTube guidance; reported this week as a September revision, but Google provides no dated change log.  
[Direct source ↗](https://support.google.com/youtube/answer/10291745?hl=en)

## 🛠 Marketing Tool Radar

**PostHog/posthog · Test carefully · MIT core; ee/ separate · Stable CLI 0.18.1**
CLI 0.18.1 strips credentials, query strings and fragments from git remote URLs before storing release metadata; the project says to rotate any token an earlier version stored. Upgrade in a disposable CI branch, inspect one staged release and rotate affected credentials before uploads resume.

**Evidence:** Tagged release and patch inspected; Tested offline via npm for version and help only, with no upload or live metadata round-trip.  
**Boundary:** The CLI reads git metadata and can send release data, source maps or symbols to the configured host; project IDs, personal tokens and source artefacts remain sensitive.  
[Open repository ↗](https://github.com/PostHog/posthog/releases/tag/posthog-cli/v0.18.1)

**matomo-org/matomo · Watch · GPL-3.0-or-later · Mature core; 6.0.0 beta**
The first v6 beta raises the minimum stack to PHP 8.1 and MySQL 8 or MariaDB 10.6, removes the SEO plugin, bundles TrackingSpamPrevention and changes plugin/API contracts. Rehearse against a synthetic staging copy, inventory plugins and custom APIs, and keep production on stable 5.x.

**Evidence:** Project-published tagged beta; the migration guide, composer requirements and actual GPL file were inspected. No runtime migration was tested.  
**Boundary:** A self-hosted trial keeps the dataset inside the chosen server boundary but concentrates analytics, database and server secrets; beta status and third-party plugin compatibility are stop conditions.  
[Open repository ↗](https://github.com/matomo-org/matomo/releases/tag/6.0.0-b1)
