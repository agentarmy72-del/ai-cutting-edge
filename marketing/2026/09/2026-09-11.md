## 📡 Marketing Signals

**Amazon Ads · ChatGPT inventory enters Amazon DSP as a US pilot · Test**
Select US advertisers can now extend Amazon Ads campaigns into ChatGPT; Delta Vacations is an early tester. Keep it as a separate pilot until query context, placement reporting, exclusions and incrementality are explicit.

**Evidence:** Confirmed by Amazon Ads on 10 September; performance and audience-value claims are platform-claimed, and the public announcement gives no pricing or measurement method.  
[Direct source ↗](https://advertising.amazon.com/library/news/amazon-ads-chat-gpt-advertising-integration)

**Google Ads · Data Manager expands and gains an uplift metric · Test**
Google is integrating Data Manager into GA and DV360, making its API universal, and adding a metric that estimates conversions recovered by first-party data. Map consent, match keys and baseline reporting before connecting more data.

**Evidence:** Confirmed by Google on 10 September; its reported performance uplifts are platform-claimed, not independent proof.  
[Direct source ↗](https://blog.google/products/ads-commerce/data-strength-updates/)

**Shopify · WhatsApp opt-in becomes a native checkout field · Act**
Stores can now collect WhatsApp marketing consent at checkout. Before enabling it, test the consent copy, timestamp/source capture, downstream suppression and withdrawal path for each market; this is channel-specific permission, not blanket consent.

**Evidence:** Confirmed in Shopify’s 10 September changelog; no conversion or deliverability evidence, and the announcement does not establish legal compliance.  
[Direct source ↗](https://changelog.shopify.com/posts/collect-whatsapp-marketing-consent-at-checkout)

## 🛠 Marketing Tool Radar

**OrtaMarco/seo-geo-mcp-server · Try · MIT · Early 1.2.0**
The newly published npm package exposes 17 SEO/GEO checks covering rendered content, schema, robots, sitemaps, hreflang and AI-crawler access. Run one public-site audit via `npx`, then verify every proposed fix against the page source.

**Evidence:** Current commit, package and licence inspected; the build, 49 unit tests and 34 live smoke calls across two MCP protocol eras passed here.  
**Boundary:** Requires Node 20.18+. It fetches caller-named and page-linked URLs; use public sites only. Exposed HTTP mode needs a token and host allow-list, and scores are heuristics—not ranking proof.  
[Open repository ↗](https://github.com/OrtaMarco/seo-geo-mcp-server)

**formbricks/formbricks · Watch · AGPL-3.0 core; SDKs MIT; EE separate · v6 release candidate**
v6 RC adds typed embedded survey data and response-context analysis, but also replaces the authorization evaluator with SpiceDB. Trial a fresh disposable Docker instance with synthetic responses; do not upgrade a production stack yet.

**Evidence:** RC.1/RC.2 notes, source, actual split licence, Docker and migration documentation inspected; no deployment was run.  
**Boundary:** The baseline stack now includes PostgreSQL, Redis/Valkey, Hub, Cube and SpiceDB. v6 has no authorization fallback and requires a guarded migration and backups; survey and contact data may be personal.  
[Open repository ↗](https://github.com/formbricks/formbricks/releases/tag/6.0.0-rc.2)
