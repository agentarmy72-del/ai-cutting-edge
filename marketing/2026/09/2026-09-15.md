## 📡 Marketing Signals

**Microsoft Advertising · synthetic-creative disclosure guidance · Act**
Microsoft makes advertisers responsible for market-specific disclosure, rights and consent, and preserving watermarks, metadata and other provenance on AI-generated or materially altered ads. Add AI-use, rights evidence and disclosure placement to creative QA before upload.

**Evidence:** Confirmed in Microsoft’s guidance surfaced on 14 September; disclosure does not rescue deepfakes, impersonation or deception, and the page sets no universal threshold.  
[Direct source ↗](https://help.ads.microsoft.com/#apex/ads/en/60265/0)

**OpenAI · Sponsored Agent ads open a brand chat inside ChatGPT · Test**
Digiday viewed and verified an early click-to-chat format; Wayfair confirmed a limited pilot whose CTA opens a branded agent instead of the advertiser’s site. If offered access, test product accuracy, logged hand-offs and separate attribution before scaling.

**Evidence:** Observed on 14 September and brand-confirmed, but not announced by OpenAI; access, pricing, measurement and ROI remain undisclosed.  
[Direct source ↗](https://digiday.com/marketing/openais-next-chatgpt-ad-format-click-to-chat-not-to-site/)

**IAB Tech Lab · GitHub replaces PDFs as the standards source of truth · Act**
Tech Lab is moving specifications to Markdown repositories, using tags and releases for final versions and issues or pull requests for corrections. Replace saved-PDF links in implementation and vendor checklists with pinned tags, then watch the standards you depend on.

**Evidence:** Confirmed by IAB Tech Lab on 14 September; living documents can change between formal snapshots, so production implementations should pin a version.  
[Direct source ↗](https://iabtechlab.com/from-pdfs-to-pull-requests/)

## 🛠 Marketing Tool Radar

**heygen-com/hyperframes · Test carefully · Apache-2.0 · Active, pre-1.0 0.8.40**
HyperFrames renders HTML, CSS and media into MP4s; 0.8.39 adds stable word IDs for caption overrides and 0.8.40 fixes audio loss in sandboxed compositions. Trial a ten-second synthetic creative locally, then compare captions, audio and frames before campaign use.

**Evidence:** Tagged releases, source, Apache-2.0 licence and setup docs inspected; no render was run, so the fixes remain project-claimed.  
**Boundary:** Local rendering needs Node 22+, Chrome or Chromium and FFmpeg; CLI telemetry sends command, performance and system data to PostHog unless disabled. Managed rendering uploads the project and requires HeyGen authentication.  
[Open repository ↗](https://github.com/heygen-com/hyperframes/releases/tag/v0.8.40)

**warmbly/warmbly · Test carefully · Apache-2.0 · Early, high-churn 0.4.12**
v0.4.12 makes mailbox disconnection queue Gmail OAuth revocation and stored-message erasure, removes an unactionable warmup spam score and fixes zero-weight routing exclusions. Use its synthetic sandbox first; verify erasure and suppression before connecting a real mailbox.

**Evidence:** Tagged release, source, Apache-2.0 licence and operating docs inspected; no deployment or email test was run, so behaviour remains project-claimed.  
**Boundary:** Self-hosting needs Docker Compose and several services and stores, while handling contacts, credentials, message bodies and tracking data. Microsoft grants still need user removal, and consent, deliverability and lawful outreach remain operator duties.  
[Open repository ↗](https://github.com/warmbly/warmbly/releases/tag/v0.4.12)
