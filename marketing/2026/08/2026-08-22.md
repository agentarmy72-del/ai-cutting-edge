## 🛠 Marketing Tool Radar

**formbricks/formbricks · Watch · AGPL-3.0 core; SDKs/EE separate · Mature project, release candidate**  
Version 5.4.0-rc.1 tightens tenant scoping for team IDs and response/contact links, and restricts feedback-record edits and deletions to owners and managers. Test a synthetic local survey and its role boundaries; keep production data off this release candidate while waiting for a stable release or backport.

**Evidence:** Project release and inspected split licence; the authorization fixes were not independently exploited or runtime-tested.  
**Boundary:** Self-hosting requires Docker, PostgreSQL, Redis and supporting services plus strong secrets. Survey responses and contact records can be sensitive, and the sample Compose leaves email verification and password reset disabled unless configured.  
[Open repository ↗](https://github.com/formbricks/formbricks)

**guestarAI/findable · Test carefully · MIT · Experimental first release**  
Version 0.1.0 runs an outside-in check of site identity, crawlability, contact routes, visible freshness and optional branded-search presence. Trial one public site you control; use the result as triage, not as ranking, traffic or conversion evidence.

**Evidence:** Inspected MIT source; all 18 bundled tests passed in an isolated run, but real-site scoring accuracy has no independent benchmark.  
**Boundary:** Python 3.10+ installs from GitHub until a package release exists. Default mode requests only the public site; `--search` sends the business-name query to Jina or Brave with an API key. Pin the release tag and do not point it at internal hosts.  
[Open repository ↗](https://github.com/guestarAI/findable)
