# Marketing Guides

This folder holds public-safe, durable agency-marketing knowledge promoted selectively from Marketing Edge editions.

A guide qualifies only when it:

- remains useful beyond one briefing window;
- identifies the agency audience, decision and limiting conditions;
- preserves canonical public sources and calibrated evidence;
- gives repeatable steps, checks or an adoption path;
- states privacy, compliance, setup or maturity caveats where material;
- adds knowledge rather than duplicating an existing guide.

Time-bound signals remain in dated editions. A creator calling something a “skill” does not make it one; executable, reusable and genuinely tested agent procedures belong under [`library/skills/`](../../library/skills/).
