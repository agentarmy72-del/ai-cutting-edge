## 🧠 Models & Platforms
**Qwen releases Qwen3.8-27B as Apache-2.0 open weights**
The 27B vision-language model supports configurable reasoning and a 262k native context window. It gives builders another model they can run or adapt without depending entirely on a closed API; the published performance figures remain vendor benchmarks.
[Official model card ↗](https://huggingface.co/Qwen/Qwen3.8-27B)

## 🛠 Agents, Tools & Open Source
**DeepSeek opens a plugin-first agent harness**
DeepSeek Harness makes its agent architecture replaceable through plugins and can be tried with one `npx` command. It is MIT-licensed but explicitly a developer preview with breaking changes, so it is useful for exploration—not production dependency yet.
[Official repository ↗](https://github.com/deepseek-ai/deepseek-harness)

## ⚖️ Industry, Policy & Trust
**Anthropic explains how Claude text watermarking works**
Anthropic says the watermark changes token selection without hidden characters, added token cost, or identifying information, and that a detection API is planned. Anyone publishing AI-assisted text should understand that provenance marking is becoming infrastructure, not just policy language.
[Anthropic explainer ↗](https://www.anthropic.com/news/claude-text-watermark)
