## AI News Brief
**Thursday, 20 August** · New privacy controls, agent permissions, open runtimes and active security guidance.

## 🧠 Models & Platforms
**OpenAI previews cross-interaction safety checks compatible with Zero Data Retention**
OpenAI says Private Safety Processing is being tested with early API customers, identifying patterns across related interactions while data stays customer-controlled or encrypted with customer-held keys. A September rollout is planned, giving eligible API teams a path to broader safety monitoring without routine prompt retention.
[Direct source ↗](https://openai.com/index/offering-zero-data-retention-for-frontier-models/)

**Grok 4.6 becomes generally available on Amazon Bedrock**
xAI says supported AWS regions now offer Grok 4.6 with a 500,000-token context window and configurable reasoning, priced at $2 input and $6 output per million tokens. Bedrock teams gain another managed model option, but should benchmark it on their own workloads.
[Direct source ↗](https://x.ai/news/grok-4-6-amazon-bedrock)

## 🛠 Agents, Tools & Open Source
**Claude’s Gmail connector gains send, reply and forward actions**
Anthropic’s support page now lists Gmail write actions for Claude. Approval remains the default; Team and Enterprise owners can decide whether members may let them run without confirmation, so admins should review that setting before wider use.
[Direct source ↗](https://support.claude.com/en/articles/10166901-use-google-workspace-connectors)

**TrueForge opens a model-agnostic agent runtime**
TrueFoundry has released TrueForge under MIT, with MCP tools, sandboxing, approvals, persistent sessions, subagents and local or hosted deployment. Its 30–75% savings figures are **claimed** from its own 14-task benchmark, so builders should reproduce the test before relying on them.
[Direct source ↗](https://github.com/truefoundry/trueforge)

## ⚖️ Industry, Policy & Trust
**FDA opens consultation on generative-AI medical devices**
The FDA’s discussion paper asks for feedback by 19 October on risk assessment, premarket competency evaluation, postmarket monitoring, foundation models and agents. It is not draft or final guidance, but developers and clinicians can still shape the US approach before expectations harden.
[Direct source ↗](https://www.fda.gov/news-events/press-announcements/fda-seeks-public-feedback-inform-regulatory-approach-generative-ai-enabled-medical-devices)

**US agencies warn of active AI-assisted attacks on Siemens PLCs**
CISA, NSA, FBI, DOE and EPA say attackers are using AI-generated scripts and public automation libraries against internet-exposed S7 controllers. Operators should urgently inventory and patch PLCs, remove them from the public internet, tighten access and monitor TCP 102/S7comm activity.
[Direct source ↗](https://www.cisa.gov/news-events/cybersecurity-advisories/aa26-231a)
