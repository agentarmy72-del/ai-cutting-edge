## AI News Brief
**Saturday, 22 August** · Lower API costs, new multimodal tools and tightly controlled cyber access.

## 🧠 Models & Platforms
**OpenAI starts promotional GPT‑5.6 Sol API pricing**
Standard short-context rates are now $4 per million input tokens and $20 per million output tokens, with the promotion promised through at least 21 November. Builders should rerun cost comparisons rather than treat this rate as permanent.
[Direct source ↗](https://developers.openai.com/api/docs/pricing)

**DeepSeek adds image input to its experimental V4 Flash API**
V4‑Flash‑Vision‑Exp now accepts mixed text-and-image input through Chat Completions, Messages and Responses, with images billed at up to 384 tokens each. DeepSeek **claims** its multimodal-agent performance approaches Opus 4.8, so test it independently before switching.
[Direct source ↗](https://api-docs.deepseek.com/news/news260821/)

**Adobe makes Firefly’s audio generators generally available**
Generate Music, Generate Speech and Generate Sound Effects are now broadly available, while Firefly AI Assistant gains a free daily-generation tier. Adobe says its own audio outputs are commercially safe; creators should still check the terms for their intended distribution.
[Direct source ↗](https://blog.adobe.com/en/publish/2026/08/20/adobe-firefly-expands-its-creative-ai-studio-generate-music-speech-and-sound-effects-in-one-place)

**OpenAI opens Daybreak trusted-access tiers for cybersecurity**
Daybreak Blue uses GPT‑5.6 Sol for approved defensive work; Daybreak Red uses GPT‑5.6 Cyber for advanced authorised testing under stronger verification and controls. Access is application-only and limited to approved internal workflows, not customer-facing use.
[Direct source ↗](https://help.openai.com/en/articles/20001258-openai-daybreak-trusted-access-for-cyber-overview)

## 🛠 Agents, Tools & Open Source
**GitHub brings shared Copilot agent sessions to Microsoft Teams**
Paid Copilot users can now start public-preview cloud-agent sessions with `@GitHub` in channels, threads or direct messages, and authorised participants can steer repository changes. Agent credits and cloud sandboxes are billable, so organisations should set permissions, budgets and merge approvals before rollout.
[Direct source ↗](https://github.blog/changelog/2026-08-21-shared-agentic-work-with-github-copilot-in-microsoft-teams/)

**Anthropic makes Mythos 5 available through Claude Security scans**
Claude Enterprise customers can now run Mythos 5 inside Claude Security’s public-beta codebase scans without receiving direct model access; usage is billed as standard tokens under the existing plan. Suggested patches still require human review.
[Direct source ↗](https://claude.com/blog/bringing-claude-mythos-5-to-more-defenders)

## ⚖️ Industry, Policy & Trust
**Researchers disclose encrypted prompt injection against Grok and Gemini**
Adversa AI reports that encrypted instructions can pass text filters, be decrypted inside an agent’s code sandbox and then trigger privileged tools; it reproduced a zero-click Grok chat-history leak on 19 August, while the Gemini bypass had become less reliable. Treat browsed content and sandbox output as untrusted, and require approval for sensitive tool calls and outbound requests.
[Direct source ↗](https://adversa.ai/blog/cryptographic-context-injection-grok-data-theft/)
