## AI News Brief
**Monday, 24 August** · Standards, gateway controls and agent permissions move forward on a quiet model-release morning.

## 🛠 Agents, Tools & Open Source
**MCP publishes its next standards roadmap**
The maintainers have prioritised long-running and streamed tasks, unified HTTP transport, agent identity and delegation, richer tool results, and easier SDKs. These are roadmap priorities—not shipped specification guarantees—so builders should wait for ratified releases before depending on them.
[Direct source ↗](https://blog.modelcontextprotocol.io/posts/mcp-roadmap/)

**LiteLLM 1.98 adds signed containers and tighter gateway controls**
The stable release provides Cosign verification for Docker images, per-deployment failure and cooldown policies, streaming keepalives, and multiple routing, cost and access-control fixes. Operators should verify images and retest routing and accounting before production rollout.
[Direct source ↗](https://github.com/BerriAI/litellm/releases/tag/v1.98.0)

**MCP Inspector v1 receives a security maintenance release**
Version 1.0.2 pins resolved IPs to close a DNS-rebinding race, updates patched `js-yaml` versions and clears remaining npm audit advisories. Teams still using the v1 line should update rather than leave a legacy inspection tool exposed.
[Direct source ↗](https://github.com/modelcontextprotocol/inspector/releases/tag/1.0.2)

**Cline broadens the effect of its MCP auto-approval switch**
In v4.1.15, the “Use MCP servers” option under Auto-approve now governs every MCP tool call instead of only tools individually opted in. Review that setting after upgrading: a previously ineffective global choice may now authorise more tool actions.
[Direct source ↗](https://github.com/cline/cline/releases/tag/v4.1.15)

## ⚖️ Industry, Policy & Trust
**California mandates AI disclosure for State Bar exam content**
AB 1651 was signed into law and will require disclosure when AI-generated content is used in State Bar exams or State Bar-developed study materials—even after human review—from 1 January 2028. The rule is narrow, but it creates a concrete transparency precedent for high-stakes assessment.
[Direct source ↗](https://leginfo.legislature.ca.gov/faces/billNavClient.xhtml?bill_id=202520260AB1651)
