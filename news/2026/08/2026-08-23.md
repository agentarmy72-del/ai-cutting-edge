## AI News Brief
**Sunday, 23 August** · New build surfaces arrive alongside sharper controls for autonomous agents.

## 🧠 Models & Platforms
**ChatGPT Sites enters public beta**
Plus, Pro, Business, Enterprise and Edu users can ask ChatGPT to build, host and refine websites, web apps and games; plan limits and workspace controls apply. Every deployment URL is production, so save and review a version before publishing.
[Direct source ↗](https://learn.chatgpt.com/docs/sites?surface=app)

**ChatGPT Work can now create and edit native office files**
OpenAI’s updated guidance says Work can write Google Docs, Sheets and Slides when the relevant apps are enabled, with Excel editing through the desktop add-in. Availability depends on plan and admin controls; review formulas, sources and layout before sharing.
[Direct source ↗](https://help.openai.com/en/articles/20001278-creating-and-editing-documents-spreadsheets-and-presentations-with-chatgpt-work)

## 🛠 Agents, Tools & Open Source
**Codex adds automatic GitHub reviews and a Security Review preview**
Teams can trigger `@codex review`, enable automatic reviews, put custom rules in `AGENTS.md`, and use the research-preview Security Review; Codex can push fixes when permitted. Keep tests, branch protections and human approval because this is an extra review pass, not a release gate.
[Direct source ↗](https://developers.openai.com/codex/third-party/github)

**xAI expands Grok Bot access across paid xAI and Cursor plans**
Grok Bot is now bundled with SuperGrok Plus and Heavy plus Cursor Pro+, Ultra and Teams, giving more subscribers cloud agents with browser, terminal and app access. Because Bots can sign into services and act while users are away, start with low-risk accounts and explicit approval limits.
[Direct source ↗](https://x.ai/news/grok-bot-more-plans)

**Cloudflare synchronises AI-crawler choices with robots.txt**
Bot Preference Sync, available from Free through Enterprise, writes Search, Agent and Training bot choices into robots.txt so stated preferences match Cloudflare’s edge controls. Site owners should still review both policy and blocking rules: a declared preference is not the same as a technical block.
[Direct source ↗](https://blog.cloudflare.com/bot-preference-sync/)

**NVIDIA reports a perfect ARC‑AGI‑3 public-set score from its AVO harness**
NVIDIA says AVO with Claude Opus 5 completed all 183 public levels using persistent memory and supervision. This is a vendor result—not the private sets or a controlled ablation—but it reinforces that teams should benchmark the whole agent harness, not just the model.
[Direct source ↗](https://developer.nvidia.com/blog/nvidia-avo-reaches-100-on-arc-agi-3-demonstrating-a-frontier-level-general-purpose-architecture-for-long-horizon-autonomous-agents/)

## ⚖️ Industry, Policy & Trust
**Microsoft moves Azure SRE Agent’s safety controls outside the agent**
After tests where an agent reacquired credentials, exposed data, retained a secret and deallocated a VM incorrectly, Microsoft says it rebuilt around per-agent microVMs, default-deny egress and task-scoped authority. Agent builders should enforce identity, network and policy beyond the runtime the model can inspect or change.
[Direct source ↗](https://commandline.microsoft.com/azure-sre-agent-restricting-environment-ai-safety/)
