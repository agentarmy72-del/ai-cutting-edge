## AI News Brief
**Monday, 31 August** · Two retirements, two agent updates and a new training-data case.

## 🧠 Models & Platforms
**OpenAI retires the standalone DALL·E GPT**

OpenAI’s dedicated DALL·E GPT left ChatGPT on 30 August. ChatGPT Images and user-created GPTs with image generation remain available, so image creation continues but saved workflows should move to the newer surface.

[Direct source ↗](https://help.openai.com/en/articles/6825453-chatgpt-release-notes#retiring-the-dalle-gpt)

**Kimi retires K2.5 and Moonshot V1 API models**

Moonshot’s live documentation says `kimi-k2.5` and the `moonshot-v1` series reach full platform sunset on 31 August. API users should move calls to a supported Kimi model and retest context, output and cost before production traffic resumes.

[Direct source ↗](https://platform.kimi.ai/docs/models)

## 🛠 Agents, Tools & Open Source
**Codex CLI 0.151 adds MCP hooks and closes sandbox gaps**

Release 0.151.0 lets extensions inspect or replace MCP tool results and fixes cases where `/cd`, restored permissions or stale Guardian decisions could weaken enforcement. MCP and remote-executor users should update, then recheck extension trust and sandbox policy.

[Direct source ↗](https://github.com/openai/codex/releases/tag/rust-v0.151.0)

**Grok Bot can now work directly with X**

Grok Bot users can connect X, while paid users receive starter API credits; bots can search posts, read timelines, check mentions or compile activity. The integration broadens social-monitoring automation, so review account permissions and source posts before acting on summaries.

[Direct source ↗](https://x.ai/news/grok-bot-and-x)

## ⚖️ Industry, Policy & Trust
**Sony and Warner publishers sue Anthropic over training data**

Sony Music Publishing, Warner Chappell and affiliates filed a US complaint alleging Anthropic illegally acquired and copied copyrighted musical compositions to train Claude, naming two co-founders as defendants. These are untested allegations with no immediate Claude access change, but the case puts data acquisition and provenance—not only model outputs—under scrutiny.

[Direct source ↗](https://www.musicbusinessworldwide.com/files/2026/08/COMPLAINT-in-Sony_Music_Publishing_US_LLC_e.pdf)
