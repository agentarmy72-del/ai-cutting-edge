## AI News Brief
**Wednesday, 16 September** · Voice AI, cloud operations and enterprise agents gained concrete new controls.

## 🧠 Models & Platforms

**Google releases Gemini 3.8 Live for real-time voice apps**

Gemini 3.8 Live and its Extended Thinking variant are now available through the Gemini API and Google AI Studio at $0.005 per audio-input minute and $0.018 per audio-output minute. Google’s performance rankings are vendor claims; the practical change is developer access to new speech-to-speech reasoning models.

[Direct source ↗](https://blog.google/innovation-and-ai/technology/developers-tools/build-real-time-voice-applications-gemini-audio/)

**Salesforce opens its Koa CRM reasoning model to pilot users**

Koa, post-trained from NVIDIA Nemotron 3 Super on synthetic CRM scenarios, is available to select Agentforce customers, with US general availability expected in winter 2026. Salesforce **claims** three-times fewer errors on its own CRM benchmark; validate that result independently before operational use.

[Direct source ↗](https://www.salesforce.com/news/press-releases/2026/09/15/koa-reasoning-model/)

**SageMaker jobs can now fall back across acceptable instance types**

New preference lists let training and processing jobs try a prioritized set of instance types and counts, then launch on the first available configuration. The feature is available across SageMaker regions and can replace custom retry logic when high-demand GPU capacity is scarce.

[Direct source ↗](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-sagemaker-training-processing-instance-pref-lists/)

## 🛠 Agents, Tools & Open Source

**Amazon Q can investigate CloudTrail in plain language**

Amazon Q Console can now query CloudTrail, associated CloudWatch logs and event data stores to answer account-activity, security and troubleshooting questions. It is available in supported AWS commercial regions, reducing the need to write queries or manually parse logs.

[Direct source ↗](https://aws.amazon.com/about-aws/whats-new/2026/09/cloudtrail-amazon-q-console/)

**AWS and Salesforce connect agents, models and data more directly**

Salesforce context is now native in Amazon Quick, Agentforce can access Anthropic and NVIDIA models through Bedrock, and zero-copy access covers more AWS data services. Several integrations are available now; OpenAI models and additional Slack agents are still forthcoming.

[Direct source ↗](https://www.salesforce.com/news/stories/aws-salesforce-enterprise-ai-expansion/)
