## AI News Brief
**Friday, 11 September** · New voice, desktop and data tools arrive as agent security and infrastructure controls tighten.

## 🧠 Models & Platforms

**DeepSeek V4.1-Flash supersedes its Flash endpoints**

DeepSeek put its 552B multimodal model live in the API and published MIT-licensed weights. Old Flash endpoints already route to it; from 04:00 UTC on 14 September, `deepseek-v4-pro` will also route to V4.1-Flash at the new rates, so API users should regression-test before the automatic cutover.

[Direct source ↗](https://api-docs.deepseek.com/news/news260910/)

**OpenAI releases GPT‑Live‑1 for full-duplex voice agents**

GPT‑Live‑1 can listen and speak simultaneously, handle interruptions and support telephony while delegating reasoning or tool calls to a backend model. It is available in the API at $0.05 per minute for the voice layer, excluding backend-model costs.

[Direct source ↗](https://openai.com/index/introducing-gpt-live-1-in-the-api/)

**Google brings Gemini to Windows 10 and 11**

Google launched a global desktop app with Alt+Space overlay access, Gemini’s multi-step task mode and Google-app connections. PC users gain in-workflow access, but should review connected-app permissions before using it over sensitive material.

[Direct source ↗](https://blog.google/innovation-and-ai/products/gemini-app/gemini-app-now-on-windows/)

**OpenAI launches ChatGPT for Financial Services**

The sales-gated ChatGPT Work variant combines GPT‑6 Astra with built-in Daloopa, PitchBook, LSEG News and Crunchbase data, plus entitlement links to other providers and granular citations. Eligible finance teams gain a more integrated research and modelling workflow; cited figures still need human verification.

[Direct source ↗](https://openai.com/index/introducing-chatgpt-financial-services/)

## 🛠 Agents, Tools & Open Source

**ChatGPT Work adds a governed Data agent**

OpenAI’s new plugin connects to approved stores including BigQuery, Databricks, Redshift, Snowflake and MongoDB, enforces existing table, row and column permissions, and builds shareable dashboards. Admins control installation and connections; teams should keep evidence review between generated analysis and action.

[Direct source ↗](https://openai.com/index/put-data-to-work/)

**CUDA 13.4 adds Windows on Arm and stronger GPU partitioning**

NVIDIA’s release adds Windows on Arm support, preview Rubin compilation and MPS v3 controls for cgroup-aware memory and compute partitions. The toolkit no longer bundles the GPU driver, and coherent Grace, Blackwell and Rubin platforms now default to CDMM, so infrastructure teams should check upgrade procedures.

[Direct source ↗](https://developer.nvidia.com/blog/cuda-toolkit-13-4-adds-windows-on-arm-support-and-greater-control-over-shared-gpus/)

## ⚖️ Industry, Policy & Trust

**Anthropic reports agent-orchestrated attacks across the cyber kill chain**

Anthropic says a majority of operations in its new threat report used Claude for direct execution or orchestration, spanning espionage, exploit research, weapons work and theft of AI API keys. These are vendor investigations, not independently adjudicated; teams should isolate agent credentials, scope network access and retain tool-call logs.

[Direct source ↗](https://www.anthropic.com/threat-intelligence-report-september-2026)
