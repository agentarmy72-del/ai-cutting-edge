## AI News Brief
**Wednesday, 2 September** · New models and tools arrived alongside tighter controls for agents, publishers and high-risk cyber capability.

## 🧠 Models & Platforms
**Anthropic releases Claude Fable 5.1 and restricted-access Mythos 5.1**

Fable 5.1 is available across Anthropic and major clouds with cache reads cut 75%; Anthropic estimates typical usage costs about 25% less, while other token rates stay unchanged. Mythos 5.1 uses the same base model with more permissive safeguards for vetted cyber and life-science work; performance gains remain vendor-reported.

[Direct source ↗](https://www.anthropic.com/claude-fable-and-mythos-5-1)

**Gemini adds agentic video analysis to three Flash models**

Google now lets Gemini 3.7 Flash, 3.6 Flash and 3.5 Flash-Lite dynamically inspect selected frames, audio and transcripts through the API and Enterprise Agent Platform. Google claims up to 88% lower token use and 66% lower cost on its tests; developers can enable it now at standard token pricing.

[Direct source ↗](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-agentic-video-in-gemini/)

**Google Pics begins rolling out for AI Pro, Ultra and Workspace**

Google’s new standalone and collaborative image editor can isolate objects, edit or translate in-image text and generate alternatives with Nano Banana. Docs and Slides integrations start now, Drive follows in the coming weeks; access is rolling out to Pro and Ultra subscribers and most Workspace business customers.

[Direct source ↗](https://blog.google/products-and-platforms/products/workspace/google-pics/)

**ChatGPT for Healthcare connects to Epic and nine public data sources**

OpenAI added governed Epic EHR access and a Healthcare Public Data plugin covering sources including PubMed, DailyMed and ClinicalTrials.gov. Healthcare teams can review authorized patient context with citations, but generated summaries still require clinical review.

[Direct source ↗](https://openai.com/index/chatgpt-connects-health-records-and-healthcare-sources/)

## 🛠 Agents, Tools & Open Source
**GitHub Copilot can now approve pull requests**

In public preview, Copilot’s code review always includes an approval assessment and, if admins opt in, its approval can satisfy a repository’s required-approval rule. Controls exist at enterprise, organization and repository levels—including allowed file paths—so teams should set the boundary before treating an agent as a reviewer of record.

[Direct source ↗](https://github.blog/changelog/2026-09-01-copilot-code-review-can-now-approve-pull-requests/)

## ⚖️ Industry, Policy & Trust
**Google tests an opt-out for generative AI Search**

Google is rolling out a Search Console toggle to a subset of UK site owners, letting them exclude their links and content from AI Overviews, AI Mode and Discover’s AI answers without changing rankings in ordinary Search. Opting out also removes AI-feature traffic and impressions, giving publishers a real control with a clear visibility trade-off.

[Direct source ↗](https://blog.google/products-and-platforms/products/search/new-controls-website-owners/)

**OpenAI designates Astra its first “Critical” cyber-capability model**

OpenAI says Astra can autonomously find unknown flaws and build exploit chains against hardened systems; that is a vendor assessment, with a system card promised at launch. Release is planned “soon,” with the strongest cyber capabilities initially restricted to testers before broader defensive access through Daybreak Blue.

[Direct source ↗](https://openai.com/index/path-to-astra/)
