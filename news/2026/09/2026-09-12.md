## AI News Brief
**Saturday, 12 September** · New controls reach agents and code review, while US and UK policy diverges on frontier-model risk.

## 🧠 Models & Platforms

**OpenAI adds Astra deployment controls and enterprise desktop plugins**

OpenAI’s new admin controls can restrict Astra to approved websites and desktop apps and manage uploads, downloads and browsing history; ChatGPT Desktop also gains Oracle Analytics, Power BI, Navan and Avalara plugins. Enterprise teams can now begin with narrower system access.

[Direct source ↗](https://openai.com/index/gpt-6-astra-next-generation-work/)

## 🛠 Agents, Tools & Open Source

**OpenAI opens the Codex agent harness through a public API**

The Agents API is now in public beta for all developers, with hosted or self-managed sandboxes, automatic context compaction, tool search, MCP and custom tools, and parallel subagents. There is no separate API fee during the beta beyond model and tool usage, but it is not yet generally available.

[Direct source ↗](https://openai.com/index/introducing-the-agents-api/)

**Amazon Q can now diagnose past-due AWS bills**

Amazon Q in the AWS Management Console can now identify unpaid invoices, explain failed payment attempts, show payment details and link to corrective actions. Billing-data and Amazon Q IAM permissions are required; FinOps teams may avoid opening a support case for routine failures.

[Direct source ↗](https://aws.amazon.com/blogs/aws-cloud-financial-management/introducing-payment-capabilities-in-amazon-q-to-resolve-past-due-balances/)

**GitHub deepens Copilot code review with shell tools and agent ensembles**

Copilot code review now auto-resolves addressed comments, writes commit messages for accepted fixes, can run builds and tests behind its agent firewall, and uses an agent ensemble for Lite reviews. Generated findings and fixes still need CI and human approval.

[Direct source ↗](https://github.blog/changelog/2026-09-11-auto-resolution-and-analysis-updates-in-copilot-code-review/)

## ⚖️ Industry, Policy & Trust

**Meta removes personal-topic suggestions from its AI assistant**

After Meta AI surfaced prompts about a user’s children and drew on family material she could already access, Meta told The Verge it fixed the issue and will stop suggesting personal-topic prompts. Meta says the assistant can still return content the querying user is permitted to see.

[Direct source ↗](https://www.theverge.com/tech/993974/meta-ai-prompt-invasive-suggestions)

**US Senate draft would put a duty of care on frontier-model labs**

Reported drafts would require labs to disclose advanced-risk findings and mitigations to the Commerce Department before release; regulators could seek a federal-court injunction, but senators remain split over state-law pre-emption. This is a live negotiation, not a new legal duty.

[Direct source ↗](https://www.politico.com/news/2026/09/11/klobuchar-thune-ai-safety-bill-faces-impasse-01073026)

**UK government rejects a national AI “kill switch”**

The Cabinet Office says blocking models in Britain would not stop development or misuse elsewhere and opposes the proposed emergency shutdown mechanism, making passage unlikely although Parliament can continue debating it. UK operators should not assume a government off-switch exists.

[Direct source ↗](https://www.bbc.co.uk/news/articles/c3eq7kl5l00o)
