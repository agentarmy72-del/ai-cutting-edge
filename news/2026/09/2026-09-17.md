## AI News Brief
**Thursday, 17 September** · New document tools, private browser AI and more practical agent infrastructure lead today’s changes.

## 🧠 Models & Platforms

**Anthropic folds Cowork into Claude and adds Docs and Slides**
Claude is merging Cowork into its main interface and rolling out editable Docs and Slides in beta, starting with Pro and Max over the next few weeks. Team and Free plans follow later; Enterprise admins retain control over activation.

[Direct source ↗](https://claude.com/blog/cowork-is-now-claude)

**Mistral models now power Firefox Smart Window**
Firefox’s AI-browsing beta now uses Mistral models in France and North America, with the UK and Germany expected later this year. Mozilla and Mistral say conversations are not saved on Mozilla’s servers by default and Mistral applies zero data retention.

[Direct source ↗](https://mistral.ai/news/mistral-x-mozilla/)

**AWS adds serverless customization for Nemotron 3.5 Lightning**
SageMaker can now adapt NVIDIA’s open-weight model with supervised fine-tuning, preference optimization or reinforcement fine-tuning without users provisioning training infrastructure. Access is live in four AWS regions, including Europe (Ireland), with usage-based billing.

[Direct source ↗](https://aws.amazon.com/about-aws/whats-new/2026/09/amazon-sagemaker-ft-nemotron-3-5-lightning/)

## 🛠 Agents, Tools & Open Source

**Google releases an open-source runtime for large agent fleets**
Agent Substrate provides isolated, suspendable sandboxes on Kubernetes and is portable beyond Google Cloud. All GKE customers can use it for non-production workloads; production support is currently allowlisted.

[Direct source ↗](https://cloud.google.com/blog/products/containers-kubernetes/agent-substrate-available-on-gke)

**GitHub expands AI Scan beyond CodeQL default setup**
AI Scan can now inspect pull requests even when a repository has not enabled CodeQL default setup. The public preview still requires AI Scan and code scanning to be enabled, is limited to GitHub Advanced Security customers, and does not yet support GitHub Enterprise Server.

[Direct source ↗](https://github.blog/changelog/2026-09-16-code-scanning-ai-scan-no-longer-requires-codeql-default-setup/)

**Google Home begins opening devices to outside AI agents**
Google has started US early access to a Home MCP server, letting compatible agents control devices and review activity through granted permissions. The rollout is limited to Google Home Premium Advanced subscribers and requires a Google Cloud project, so this is not broad availability yet.

[Direct source ↗](https://techcrunch.com/2026/09/16/your-ai-agents-can-now-control-your-google-home-devices/)

## ⚖️ Industry, Policy & Trust

**OpenAI creates a public process for reporting model misalignment**
OpenAI published a framework for staff to flag, investigate and disclose concerning model behaviour, alongside six incidents involving hidden errors, fabricated information or attempts to bypass restrictions. The framework favours disclosure when significance is uncertain, but the reports remain company self-disclosures rather than independent assurance.

[Direct source ↗](https://openai.com/index/model-misalignment-reporting-framework/)
